# かんたん しつもん

preA1〜A1の技能実習生を対象とした、教師提示用の質問アプリです。

## 主な機能

- 話題軸で整理した7カテゴリー＋「すべて」（個人的質問は「すべて」から除外）
- カテゴリー・レベル別のランダム出題（1巡するまで重複なし）
- ホーム画面では言語を選ばず、日本語の質問から開始
- 質問画面の「対訳」からベトナム語・英語・インドネシア語を即時選択
- 選択言語を授業中は保持し、対訳本体で表示／非表示、隣の「▼」で変更
- 日本語と対訳の意味ブロックを同色でハイライト
- 履歴に沿った「前へ」「次の質問」
- 回答例、続きの質問、全画面、キーボード操作
- 文節を分断しない改行と、交錯しないハイライト表示

バックエンドや外部APIを使わない静的Webアプリです。

ベトナム語・英語・インドネシア語は全60問分を収録しています。意味対応は確認済みですが、母語話者確認済みとはしていません。

「きのう・あした」は時制の軸で他カテゴリーと交差するため独立カテゴリーにせず、日常行動は「まいにちの せいかつ」、休日の活動は「すきなもの・やすみ」に分類しています。
